# particleFilter

This project is about helping a robot figure out where it is as it moves around, even when its sensors and movements are a bit noisy or imperfect. It uses a method called a particle filter, which creates lots of little guesses (particles) about the robot’s position and updates them as the robot moves. The particle_filter.py script handles creating these guesses, updating them with movement data, and adding some random noise to make it realistic. The utils.py file has helper functions like adding noise or rotating points to help with the calculations. Together, these scripts let the robot keep improving its guess of where it is over time, similar to how a person might use a map and their own steps to stay on track. The project is built in Python, using NumPy for the math and some extra code modules to manage the grid and particles.
